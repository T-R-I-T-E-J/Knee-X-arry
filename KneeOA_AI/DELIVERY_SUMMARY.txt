## 🚀 Getting Started (3 Simple Steps)

### Step 1️⃣: Setup Environment
```bash
cd c:\Users\trite\Downloads\Knee_x-ray\KneeOA_AI
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### Step 2️⃣: Prepare Data
```bash
mkdir -p data/raw/MedicalExpert-I/{0Normal,1Doubtful,2Mild,3Moderate,4Severe}
# Copy X-ray images to corresponding folders
```

### Step 3️⃣: Train or Deploy
```bash
# Option A: Train
python train.py --dataset-path data/raw --epochs 100

# Option B: Web UI
python ui/app.py
# Open http://localhost:7860
```
